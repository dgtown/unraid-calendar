Send to display

Your Outlook "published calendar" ICS link. It's saved on this phone only.

The display holds about 300 events; if there are more, it gets the nearest ones.

Help
  • Getting the Outlook link: Outlook on the web → Settings → Calendar → Shared calendars → Publish a calendar. Pick your calendar and Can view all details (otherwise every event just says "Busy"), then Publish and copy the ICS link.
  • "Outlook won't let this page read the link": open the ICS link in Chrome so it downloads, then tap Use a downloaded .ics file instead and pick it (it's in Downloads).
  • Can't find the display: it only listens for a phone when it isn't on its home Wi-Fi. Turn on Bluetooth and Location on the phone, and keep within a few metres.
  • "The display knows a different phone": the display only takes calendars from the first phone that sent one. On the display, hold the screen for 5 seconds, let go, join the Calendar-Setup Wi-Fi, tick Let a different phone send and Save. Clearing this site's data in Chrome has the same effect as a new phone.
  • Your calendar goes straight from this phone to the display. It's never sent anywhere else.
